# TechNova Revenue Visualization Dashboard

An interactive data visualization dashboard built with **Chart.js** to analyze TechNova's first-half financial performance (Jan–Jun).

## Live Demo
🌐 **Website Link:** https://technova-revenue-dashboards.netlify.app/

## Dashboard Overview
- **Monthly Performance (Line Chart):** Compares **Revenue**, **Expenses**, and **Profit** across January to June with the legend positioned at the bottom and a chart title.
- **Monthly Revenue (Bar Chart):** Displays monthly **Revenue** (`50,000` to `80,000`) with distinct colors for each month.
- **June Profit Distribution (Pie Chart):** Breaks down June's profit (`35,000`) into **Reinvestment (40%)**, **Salaries (35%)**, and **Misc (25%)**.

## Built With
- HTML5 / CSS3 / JavaScript
- [Chart.js](https://chartjs.org)
